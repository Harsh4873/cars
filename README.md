# Cars

A swipe deck of newer cars near Seven Lakes High School, published at `https://harsh.bet/cars/`.

The deck is sedan listings checked on October 19, 2026. Asking prices run about $15,000 to $22,000. Every car is about 10 to 25 minutes from Seven Lakes, in Katy or on the Richmond and Rosenberg strip. Each card has the asking price, miles, the seller's claims, and the known weak spots for that model. Passing and matching save in this browser immediately.
